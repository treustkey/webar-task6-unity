EXPERIMENT 06 · UNITY / WEBXR

Объект в центре взгляда

Страница исходного проекта. WebGL-сборка ещё не создана: в установленном Unity отсутствует WebGL Build Support.

Эта страница не является Unity WebGL-приложением.

  1. Установить WebGL Build Support для Unity 6000.3.7f1.
  2. Открыть проект и импортировать BiRP Sample из WebXR Interactions.
  3. Подключить WebXR Export в XR Plug-in Management и скопировать WebGLTemplates.
  4. Выполнить WebAR → Create Scene, затем WebAR → Build WebGL.
  5. Проверить HTTPS-страницу на телефоне и записать результаты.
